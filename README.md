
# AfriConnect Summit

AfriConnect Summit est un site web vitrine conçu pour présenter un sommet technologique panafricain réunissant développeurs, entrepreneurs, investisseurs et passionnés de l'innovation à travers l'Afrique.

---

## 📂 Structure du projet

```
.
├── index.html
├── programme.html
├── intervenants.html
├── contact.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── main.js
└── image/
    ├── (logos, sponsors, intervenants, illustrations...)
```

---

## ✨ Fonctionnalités

- Design responsive (Desktop, Tablette et Mobile)
- Navigation intuitive
- Hero avec compte à rebours
- Présentation du programme
- Présentation des intervenants
- Section Sponsors (Gold, Argent et Bronze)
- Formulaire de contact
- Bouton retour en haut
- Mode clair / sombre
- Animations au défilement

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🚀 Lancer le projet

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Installer l'extension **Live Server** (recommandé).
4. Ouvrir `index.html` puis lancer **Open with Live Server**.
